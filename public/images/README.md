# Resim Yükleme Rehberi (Image Upload Guide)

Bu klasör (`public/images/`), web sitesinde kullanılacak tüm ürün, afiş, logo ve kurumsal görsellerin saklandığı ana dizindir.

## Resim Nasıl Eklenir?

1. Eklemek istediğiniz görseli (örneğin: `urun-1.jpg`, `monnica-serum.png`, `tesis-1.jpg`) bu `public/images/` klasörüne kopyalayın.
2. Web kodunda veya ürün listesinde görsel yolunu şu şekilde belirtin:
   `/images/urun-1.jpg`

## Örnek Dosya Adlandırma Kuralları:
- Ürünler için: `/images/urun-mutfak-yagsokucu.jpg`
- Hero/Banner için: `/images/hero-banner.jpg`
- Hakkımızda için: `/images/kurumsal-tesis.jpg`

## Desteklenen Formatlar:
`.jpg`, `.png`, `.webp`, `.svg`, `.avif`
